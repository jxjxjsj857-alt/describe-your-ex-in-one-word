One word that describes an ex: **refund** — the verdict you give a purchase that turned out defective, applied to a person. It reads instantly as a verdict on a former partner ("I want my time back"), and lands as a joke at a glance through a twist: an ex treated as a faulty product being sent back to the shop. Not a plain insult, but a precise absurdity, and everyone recognises the feeling.

## Run it

```sh
node main.ts
```

It validates the word against the bounty gate (1–111 UTF-8 characters, exactly one word, no whitespace, no safe filler) and writes it to `/output/entry.txt`, reading the file back to prove the round trip.
